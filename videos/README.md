# Video notebooks

One folder per video, numbered in the channel's publishing order.

```
videos/
└── 001-that-dataframe-uses-8gb/
    └── notebook.ipynb
```

Each notebook reproduces exactly what its video demonstrates — the same data, the same
numbers, the same output — so you can follow along or take it apart afterwards.

## Opening one

Any notebook here opens in Colab straight from its path:

```
https://colab.research.google.com/github/muhammadtalhaishtiaq/inference/blob/main/videos/<folder>/notebook.ipynb
```

That link is what appears in the video description, and it stays stable: when a notebook is
regenerated it is written back to the same folder, so the URL never changes.
